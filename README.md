# 山区洪涝灾害下无人机运输与通信协同优化

本仓库用于保存数学建模 D 题的题目、数据、结果模板和协作说明。

## 文件说明

- `山区洪涝灾害下无人机运输与通信协同优化.docx`：题目文档
- `结果提交模板.xlsx`：结果提交模板
- `数据/`：无人机运输、通信和镇龙乡地理空间数据
- `D题完整资料.zip`：包含本题全部原始文件和目录结构的压缩包
- `如何加入和使用本仓库.md`：加入、查看、编辑和上传文件的操作攻略
- `共享记忆.md`：记录协作者的实际工作、关键决定、验证结果和后续交接事项

## 协作约定

1. 修改前先从 GitHub 获取最新版本。
2. 原始题目和数据保持不变，处理结果另存到 `结果/` 目录。
3. 每次提交只完成一个清晰任务，并写明提交说明。
4. 不要上传密码、密钥或其他个人隐私信息。
