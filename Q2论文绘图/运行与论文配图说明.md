输入来自 https://github.com/jinding-droid/Drone-transportation 的main分支，参考提交 `9b407179971ab49327fc2d23b70ac620ae1c0856`，获取日期2026-09-26。本包附带五张发布CSV，脚本不重跑优化，不修改输入；每次运行记录输入SHA256。

## 运行

解压后，在本文件所在文件夹打开终端：

```powershell
python -m pip install numpy matplotlib
python .\代码\q2_figures.py
```

输出在 `结果/Q2论文图`，6组图各含600dpi PNG、PDF和SVG，共18个文件。已附上实际运行生成的图片。Word可使用PNG，LaTeX可使用PDF。

脚本可复制到你们仓库的 `代码` 目录，自动读取该仓库 `结果` 目录。也支持：

```powershell
python .\代码\q2_figures.py --results "F:\你的仓库\结果" --out "F:\你的仓库\结果\Q2论文图"
```

其他参数：`--dpi 300` 调整PNG分辨率，`--font "Microsoft YaHei"` 指定已安装中文字体。没有中文字体时请安装思源黑体（Noto Sans CJK SC）。

## 推荐图注与分析口径

| 图 | 可用图注与用途 |
|---|---|
| 图1 无人机调度甘特图 | 三类运输无人机的任务占用与多架次衔接。条带覆盖任务开始至返回O01，包含准备/装载、飞行和交接，不是纯飞行时间；条内首行为架次编号后三位，次行为访问服务区顺序（S1即S001）。空白表示无任务占用。 |
| 图2 电池周转甘特图 | 电池在运输任务与充电阶段的占用。彩色表示任务占用，灰色斜线表示返场后充电，空白表示可用但未安排任务；虚线为全部运输任务返场时刻。不可把灰色充电时长计入无人机实体占用。 |
| 图3 交付时效 | 货箱实际交付时刻与硬时限/期望送达时刻对比。对角线下方表示提前送达；无硬时限货箱不进入左图，但全部货箱进入右图。重合坐标聚合为圆点，面积随箱数增加，不采用随机抖动改变数据。 |
| 图4 累计交付进度 | 累计交付货箱数随时间的变化。阶梯以货箱计数，不按质量或价值加权。两条竖线分别表示最后交付和最后返场，体现交付完成与机队任务完成的区别。 |
| 图5 机型工作量与能耗 | A、B、C型承担的架次数、运输能耗及累计实体占用时间。累计占用为各架次的返回时刻减开始时刻后求和，不能写成该机型或整个机队的makespan。 |
| 图6 方案比较 | 已发布候选方案的最晚返场与运输能耗对比。编号在左右图对应，星形为当前时效推荐方案；少架次方案存在11箱普通物资迟到，不能将其视为同等零迟到方案。散点是已发布方案集合，不是完整Pareto前沿。 |

正文建议优先图1、图2和图6；图3/图4可择一说明交付表现，图5可作为补充。图中自带标题，正式排版若另加图注可删除脚本相应 `title` / `suptitle`。

## 校验与边界

脚本运行前核对：80箱唯一覆盖、货箱与架次/服务区映射、交付窗口、返航SOC、非负时间、飞机占用互斥、电池从任务开始至充电结束的互斥、电池台账与任务一致性、发布指标与方案对比首行一致性。源CSV时间保留三位小数，比较容差为0.002 s；未重算能量模型、充电公式或重新证明优化最优性。

运行输出 `数据核对与来源.json` 包含源文件哈希与核验指标。重新获取main结果后请重画图；不可混用不同版本的五张CSV。
