# 1—4题新增论文图：优先推荐的8组

本包实现上一轮优先推荐的8组图，不重复原先24组图。附带实际生成的600dpi PNG、PDF、SVG及运行所需原始数据、发布CSV和物理内核。参考仓库main提交：9b407179971ab49327fc2d23b70ac620ae1c0856。

## 运行

解压后，在本文件所在目录打开终端：

```powershell
python -m pip install numpy scipy matplotlib openpyxl
python -B .\代码\extra_figures.py
```

输出在 `结果/新增论文图`。不要只复制extra_figures.py：同目录core.py、q3.py、q4.py以及数据和结果目录均为依赖。脚本只绘图和校验，不重跑原优化器，不改变原结果。

更细的通信网格与时间采样：

```powershell
python -B .\代码\extra_figures.py --grid 121 --dt 0.2 --dpi 600
```

默认覆盖网格65×65、真实轨迹步长不超过1秒；增加精度会增加运行时间。可用`--out`指定独立输出目录。Windows自动选择微软雅黑/黑体；其他系统请安装Noto Sans CJK SC。

## 图注与解释

1. **Q1地形与飞行高度剖面**：对O01至S001、S004、S008提取DEM密采样高程，按当前core.py确定巡航海拔。实线飞行轨迹含两端垂直升降，地面+50m仅是巡航净空参考，不要求起降段也始终高于该线。图采用源模型的采样口径，不是新增的逐栅格严格净空证明。
2. **Q1质量—体积双约束**：按真实箱号从附件重算质量与体积，分别除以额定载质量和装载体积。与此前“最大安全载荷利用率”的分母不同。两项都未满不表示方案错误，可能受能耗、不可拆箱或全局组批目标影响；不能只凭接近100%就证明对应约束为最优解中的绑定约束。
3. **Q2 DEM运输航线**：按最终访问顺序恢复有向航段，三幅图分别展示A/B/C机型。线宽随使用次数增加，节点标注真实编号；正反向航段可能重叠，航线是水平投影，不是贴地飞行或地形避障路径搜索结果。
4. **Q2资源并发占用**：运输机从任务开始占用至返场；电池从任务开始占用至充电完成。按半开区间、毫秒精度计算事件曲线。核对峰值没有超过附件库存；峰值达到库存只能说明该时刻满负荷，不能单独证明增加该资源一定缩短工期。
5. **Q3通信盲区与中继改善**：在固定离地50m、65×65网格上，分别计算第30/50/100分钟的链路可用性。只使用当时已建链且未结束服务的中继，回传和接入均须满足原双向阈值。星形为网关（源模型位于O01上方），三角形为在线中继。红色为该高度与时刻下不能通信，灰色可直连，绿色仅中继可用；不代表全部高度、时段或实际运输轨迹均有同样状态，不是连续覆盖认证。
6. **Q3典型架次链路裕量**：选取中继依赖累计时间最长的两个运输架次，依据原模型重建实际爬升/巡航/下降/交接轨迹。裕量=允许路径损耗−实际路径损耗，中继取接入和回传两跳裕量较小者，只在中继在线窗口绘制。零线以上表示该采样点可用。纵轴为对称对数轴（±5dB内线性），避免近网关的高裕量掩盖零线附近变化。图线连接离散样本，不构成连续通信证明；中继在线但未被分配给该架次的链路也作为可选链路展示。
7. **Q4分组资源峰值机制**：重算所有8种资源在各组的区间占用，并与发布配置逐项核对。图选择A型电池和中继机，两种分组各一幅；显示合计占用峰值与各组峰值之和。A电池体现不同组峰值错位，中继机在本例两者相等，仍可能因跨组复制任务而高于原Q3资源需求。详细8种资源结果见分组峰值重算.csv。电池含充电，中继机含300秒周转。
8. **Q4不可拆分关系图**：同一运输架次访问的相邻服务区连边，连通分量形成11个强制同组单元，其中{S003,S007,S011,S015}通过传递关系同组，{S002,S009}同组，其余单站。图布局仅表达关系，无地理意义。未把共同使用中继作为强制同组条件。

## 输出数据与证据

- `通信切片采样.npz`：经纬度、时间、离地高度、通信类别（0不可用、1直连、2仅中继，NaN无效地形）。
- `链路裕量采样.csv`：典型架次逐时间样本；中继不在线时留空，不记为0。
- `分组峰值重算.csv`：分组后合计占用峰值、各组峰值和及二者差。
- `来源与核验.json`：模型代码、数据与结果输入SHA256、采样参数、Q2峰值及Q4峰值核验结果。

Q3复用main的遮挡密采样和附加损耗判据，未擅自换成新的无线模型。Q4先核对冻结Q3的五张输入哈希；任何不匹配都会停止，避免新旧版本混用。

此前候选表中另外列出的能耗—载荷曲线、交付提前量分布、中继高度敏感性、CV阈值敏感性不包含在本次8组优先图中；本包不声称完成新的鲁棒优化或Pareto前沿搜索。
