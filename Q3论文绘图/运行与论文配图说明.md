# 第三问论文绘图

来源：https://github.com/jinding-droid/Drone-transportation 的main分支，参考提交 `9b407179971ab49327fc2d23b70ac620ae1c0856`，获取日期2026-09-26。包内六张发布CSV保持原样，节点快照从仓库原始压缩包的《调度中心与服务区.xlsx》提取并记录来源哈希。

## 运行

在解压文件夹内打开终端：

```powershell
python -m pip install numpy matplotlib
python .\代码\q3_figures.py
```

输出到 `结果/Q3论文图`：六组图各含600dpi PNG、PDF、SVG，共18个图文件，另有来源及校验JSON。已附实际运行的图片，Word可直接插入PNG，LaTeX可插入PDF。

移到自己的仓库时，复制 `代码/q3_figures.py` 至仓库代码目录，同时将 `结果/Q3_绘图节点.json` 放到仓库结果目录；六张原Q3 CSV继续使用仓库发布版本。脚本不重跑优化，不读取Q2旧结果。

```powershell
python .\代码\q3_figures.py --results "F:\你的仓库\结果" --out "F:\你的仓库\结果\Q3论文图"
```

可选 `--nodes "节点快照路径.json"`、`--dpi 300`、`--font "Microsoft YaHei"`。若本机没有中文字体，请安装思源黑体（Noto Sans CJK SC）。

- 运输22架次：A8/B8/C6；中继3架次，实际由R01、R02两架中继机承担。
- 联合完成时间6926.1511841 s，约115.44 min。

- 中继架次编号Q3-R01由实体机R02执行，Q3-R02及Q3-R03由实体机R01执行。架次号与机号不能混淆。

## 图注及使用位置

| 图 | 建议图注与分析口径 |
|---|---|
| 图1 运输中继协同甘特图 | 运输无人机与中继无人机在统一时间轴上的任务衔接。运输条带覆盖任务开始至返场，条内为运输架次编号后三位；中继彩色段为建链完成至服务结束，灰段包括准备、外飞、建链及返场等非服务阶段，斜线段为返场后5分钟周转。联合完工不包含最终返场后的周转。中继条内R01/R02/R03为架次号后缀，纵轴R01/R02才是实体机。 |
| 图2 通信保障时间线 | 各运输架次导出区间中的直连与中继保障切换。灰色为直连，其他颜色对应三个中继架次。空白可能处于任务开始前或起飞前准备阶段，不可直接称为通信中断。架次ID沿用Q2前缀，但数据全部来自Q3，不能据此前缀认定沿用了Q2原时间线。 |
| 图3 通信保障工作量 | 左图按运输架次累加直连及各中继保障时长，单位为“运输架次·min”；右图按半开区间计算同时接受该中继保障的运输架次数。这不是数据流量或频谱容量分析；同一中继可同时服务多架运输机，因此左图累计值可大于驻守窗口长度。 |
| 图4 中继驻守位置 | 调度中心、服务区与三个中继驻守点的平面位置示意。横纵坐标为相对O01的局部近似距离，采用等距比例；中继标注的是海拔，不是离地高度。图中无地形、覆盖边界、通信网关或实际无线链路，不能据点间距离判断通信可行。 |
| 图5 运输中继能耗构成 | 当前方案运输与中继总能耗占比及各中继架次能耗。该图采用Q3汇总表和中继明细，中继增加的通信服务开销不应被遗漏。 |
| 图6 协同方案比较 | 三个已发布Q3方案的联合完成时间及运输/中继能耗对比。左右图编号一致；均为发布候选，不是完整Pareto前沿。不能将Q2的运输能耗直接视为本Q3运输能耗，因为机型、批次和时间安排已调整。 |

正文优先图1、图2、图4；图5或图6用于结果分析，图3可放补充分析。若论文另配正式图注，可删除脚本中的对应title/suptitle。

## 校验和证据边界

绘图前核对：80箱唯一覆盖、交付架次和访问服务区映射、交付窗口、SOC、运输机互斥、中继实体机占用及300s周转、通信导出区间衔接与返场边界、被引用中继的服务窗口、能耗和指标一致性。时间容差0.002s用于CSV三位小数舍入，未改变源数据。

本次校验未重新计算起飞时刻，因此通信表首区间是否严格等于起飞时刻需由原物理验证器判断；也未重算DEM、链路损耗、能量、运输电池和中继组件充电。226条导出区间的表间一致性不等于连续时间通信严格证明。共享记忆记载的0.5s/0.1s采样未发现中断，也不能在论文中改写为数学上的连续认证。

中继SOC筛查采用20%基准安全余量；若模型参数更新，绘图校验条件也需同步。CSV/节点输入SHA256及本次指标记录在 `数据核对与来源.json`，用于防止新旧版本混用。

本次仅新增本地绘图脚本、图件和共享记忆，未修改求解器或发布CSV，未提交或推送GitHub。
